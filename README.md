## Featured Projects

### 1. [NyaySetu – AI-Powered Legal Platform](https://github.com/tusharsach16/LawProject)

A full-stack legal platform designed for the Indian legal ecosystem, connecting users with lawyers and providing AI-powered legal assistance, interactive mock trials, and video consultations.

**Key Features:**
- AI-powered legal assistant using Google Gemini
- Interactive mock trials and AI-based trial analysis
- WebRTC video consultations and lawyer appointment booking
- Multilingual support

**Tech Stack:** React, TypeScript, Node.js, Express, MongoDB, Redis, WebRTC, Socket.IO, Google Gemini, Razorpay

**[GitHub Repository](https://github.com/tusharsach16/LawProject) | [Live Demo](https://nyaysetu-psi.vercel.app/)**

### 2. [Agency Dashboard – Real-Time Project Management](https://github.com/tusharsach16/agency-dashboard)

A full-stack agency management platform designed to streamline client projects, team collaboration, task assignments, and real-time activity tracking.

**Key Features:**
- Role-based access control
- Real-time activity feeds and online user presence
- Task management and notifications
- Secure authentication and database operations

**Tech Stack:** React, TypeScript, Node.js, Express, PostgreSQL, Prisma, Socket.IO, Docker

**[GitHub Repository](https://github.com/tusharsach16/agency-dashboard) | [Live Demo](https://agency-dashboard-ten-chi.vercel.app/)**

---

### 3. [GigFlow – Freelance Marketplace](https://github.com/tusharsach16/GigFlow)

A full-stack freelance marketplace where clients can post gigs and freelancers can submit bids through a streamlined hiring workflow.

**Key Features:**
- Separate roles for clients and freelancers
- Gig creation and bidding functionality
- Atomic hiring workflow using MongoDB transactions
- Real-time notifications using Socket.IO

**Tech Stack:** React, Node.js, Express, MongoDB, Redux Toolkit, Socket.IO, JWT, Tailwind CSS

**[GitHub Repository](https://github.com/tusharsach16/GigFlow) | [Live Demo](https://gig-flow-sable.vercel.app/)**

---

### 4. [ErrorNest – Error Monitoring Platform](https://github.com/tusharsach16/errornest)

A self-hosted error monitoring platform that helps developers track, group, search, and manage application errors through a centralized dashboard.

**Key Features:**
- Multi-project error tracking
- API key management and automatic error grouping
- Role-based team access
- Email and Slack alerts for critical errors

**Tech Stack:** Next.js, TypeScript, PostgreSQL, Prisma, Tailwind CSS, Auth.js

**[GitHub Repository](https://github.com/tusharsach16/errornest) | [Live Demo](https://errornest.vercel.app/)**
